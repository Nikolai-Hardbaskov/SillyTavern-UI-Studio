# SillyTavern UI Studio — Release (версия 0.3.0)

Небольшое **мобильное UI-расширение** для SillyTavern: рядом со штатным меню появляется стрелка выдвижной панели (слева по умолчанию), а в **Theme Studio** можно менять оформление через отдельный предпросмотр без немедленного изменения чата. После проверки стрелки штатную панель можно скрыть вручную.

## Новое в версии 0.3.0

- **Шрифты:** теперь 46 вариантов выбора — 12 системных/семейств и 34 дополнительных гарнитуры Google Fonts. Дополнительные шрифты загружаются через `fonts.googleapis.com` **только после их выбора**. Нужен интернет; если выбранный шрифт недоступен или не поддерживает русские буквы, браузер подставит запасной. Это не локально установленные файлы шрифтов.
- **Текст модели и пользователя независимо:** шрифт, размер 12–40 px, насыщенность 100–900, курсив, расстояние между буквами, выравнивание слева/справа/по центру/по ширине и цвет.
- **Аватарки:** 16 готовых вариантов, включая горизонтальный и вертикальный прямоугольники, овал, капсулу, арку и асимметричную форму. Ширину и высоту можно менять отдельно. Для «Своей формы» есть четыре отдельных угла, а также тип, цвет, толщина рамки и тень.
- **Сообщения:** 9 типов рамок, расширенное закругление углов, несколько видов теней и градиентов для карточек.
- **Совместимость:** старые темы с одним значением размера аватарки автоматически сохраняют свои пропорции и внешний вид при обновлении, пока ты сама их не изменишь.
- **Сохранение только вручную в Theme Studio:** предпросмотр не изменяет настоящую переписку до нажатия «Сохранить изменения». Оригинальные настройки SillyTavern работают по-прежнему.

## Что работает в этой версии

- **Черновик и ручное сохранение v0.2.9:** изменения шрифтов, размеров, цветов, рамок, аватарок и других настроек Theme Studio сразу показываются в мини-чате предпросмотра, но **не меняют настоящий чат и не записываются в настройки SillyTavern**, пока не нажата кнопка **«Сохранить изменения»** внизу панели. **«Отмена»** возвращает предыдущие настройки; закрытие с несохранёнными правками требует подтверждения. Это касается также добавления декора, выбора иконок, пресетов, импорта и сброса. Перетаскивание стрелки и уже сохранённых украшений непосредственно на экране чата — отдельные действия, их положение сохраняется после отпускания.
- **Предпросмотр v0.2.8:** в Theme Studio на вкладках **Текст**, **Сообщения**, **Аватары** и **Темы** закреплён мини-чат с образцами ответа модели и сообщения пользователя. Он показывает шрифты, размеры и цвета текста, межстрочный интервал, рамки, углы, подложки, размеры и форму аватарок. Предпросмотр остаётся перед глазами, пока список параметров прокручивается; его можно свернуть и развернуть. Это демонстрация стилей, не реальные сообщения и не их редактирование.
- **Срочное исправление v0.2.7:** убрана оставшаяся ссылка на удалённый модуль поиска, которая вызывала ошибку JavaScript при касании стрелки и мешала открывать главное меню в версии 0.2.6. Ранее сохранённые настройки и украшения не затрагиваются.
- **Декор v0.2.6:** встроенный каталог и поиск Openclipart убраны из Theme Studio по просьбе пользователя.
- **Загрузка по ссылке:** можно вставить прямой адрес PNG на любом HTTPS-сайте, например `https://example.com/flower.png`. Адрес должен вести к самому файлу `.png`, а не к странице с картинкой. Поддерживаются URL с параметрами после `.png` (`flower.png?size=500`). UI Studio проверяет, открывается ли изображение, и добавляет его в чат.
- **Загрузка из галереи телефона:** кнопка выбора PNG открывает системный выбор изображения/файла мобильного браузера. Локальные PNG до 3 МБ уменьшаются до 320 пикселей (или меньше при необходимости), сохраняя прозрачность, и сохраняются в настройках SillyTavern.
- **Совместимость с сохранёнными темами:** старые украшения из Openclipart и их координаты остаются на месте после обновления, хотя больше не предлагаются в каталоге. Никакие чаты не удаляются.
- **Ограничения внешних сайтов:** если сайт блокирует вставку изображений на другие страницы, перестаёт отдавать файл или меняет ссылку, украшение по ссылке может перестать показываться. В таком случае скачайте PNG на телефон и загрузите через галерею. UI Studio не скачивает чужие изображения в общий репозиторий и не пытается обходить ограничения сайтов.

- **Декор v0.2.3:** слой украшений поднят над чатом и адаптирован к высоте мобильного экрана. Новые украшения появляются ближе к центру, после закрытия Theme Studio их можно перемещать пальцем; размер меняется в списке украшений.
- **Прозрачность:** фон картинки автоматически не удаляется. Выбирайте исходные PNG с прозрачным фоном.

- **Исправление положения стрелки v0.2.2:** вертикальная позиция теперь задаётся относительно высоты видимого экрана (`dvh`), а не процента высоты контейнера, которую может менять сторонняя тема. Положение у нижнего края ограничено так, чтобы стрелка оставалась на экране. Проверка на конкретном телефоне всё ещё необходима.
- **Безопасный запуск v0.2.1:** штатная верхняя панель остаётся видимой, пока вы сами не включите скрытие в Theme Studio → Общее. При обновлении с v0.2.0 прежняя настройка скрытия не применяется автоматически до повторного подтверждения через переключатель.
- **Аварийный режим:** параметр `?stui_safe=1` в адресной строке SillyTavern временно отключает UI Studio на следующей загрузке. Для возвращения UI Studio удалите этот параметр и обновите страницу. Настройки и чаты остаются нетронутыми.
- Все найденные штатные разделы из верхней панели SillyTavern собраны в одном левом меню. Пункты открывают **оригинальные панели**, поэтому API, пресеты, миры, персонажи и другое продолжают работать как прежде.
- Если другое расширение (например, Horae) добавляет собственную панель в стандартную верхнюю полосу, UI Studio покажет её автоматически. Для нестандартных кнопок, расположенных вне верхней полосы, может потребоваться отдельная интеграция.
- Стрелка перемещается пальцем по вертикали, а в Theme Studio можно выбрать **левую или правую сторону**, ширину, высоту, цвет подложки, цвет значка и непрозрачность.
- **Автоматическое затухание:** после заданной паузы стрелка становится полупрозрачной; при касании снова проявляется. Яркость после затухания и задержка настраиваются, функцию можно отключить. Даже в затухшем виде стрелка не исчезает полностью.
- Никакого режима «почти спрятанной узкой стрелки» по умолчанию нет — элемент остаётся достаточно крупным для нажатия на телефоне. Верхнюю панель можно показать обратно.
- Независимые шрифты, цвета и размеры текста модели и пользователя; межстрочный интервал.
- Рамка, форма углов, прозрачность и цвет карточки сообщения; отдельная подложка всего чата.
- Размер, форма, положение и рамки аватарок.
- Замена **иконок левого меню** готовыми значками или своими небольшими изображениями.
- Украшения поверх чата: добавление PNG по прямой ссылке или из галереи телефона, удаление, перетаскивание пальцем и настройка размера. Старые символы и эмодзи больше не предлагаются.
- Сохранение нескольких тем, импорт и экспорт JSON, сброс внешнего вида.
- Настройки хранятся средствами SillyTavern, а не только в браузере.

## Как добавить декор

1. Откройте стрелку → **Theme Studio → Декор**.
2. **Вариант А — из интернета:** на любом сайте скопируйте прямую ссылку на `.png` (не на страницу просмотра) и вставьте её в поле **PNG по ссылке с сайта**. Нажмите **Добавить**.
3. **Вариант Б — из галереи:** сохраните PNG на телефон или подготовьте свой файл, нажмите **Выбрать PNG из галереи или файлов** и выберите его в системном окне. Нужен PNG размером не больше 3 МБ.
4. Ниже появится список добавленных украшений. На экране одновременно можно разместить до 15 украшений.
5. Нажмите **«Сохранить изменения»** внизу Theme Studio, затем закройте панель: украшение появится ближе к центру экрана. Удерживайте его пальцем и перемещайте по переписке. Размер меняется ползунком в списке (новый размер также нужно сохранить кнопкой).
6. После установки обновления обязательно обновите **страницу браузера**.

## Установка из GitHub (рекомендуется)

1. В SillyTavern откройте **Extensions → Install Extension**.
2. Вставьте URL: `https://github.com/Nikolai-Hardbaskov/SillyTavern-UI-Studio`.
3. Нажмите **Install**, при необходимости выберите ветку `main`. Обновите страницу.
4. Убедитесь, что стандартные верхние иконки остались на месте и появилась стрелка UI Studio.
5. Только после этого при желании откройте **Theme Studio → Общее** и включите «Скрыть стандартные верхние иконки после проверки стрелки».

## Аварийное восстановление, если стрелка не отображается

1. В адресной строке браузера добавьте к URL SillyTavern `?stui_safe=1` и откройте страницу заново. Если в адресе уже есть `?`, добавьте `&stui_safe=1`.
2. Расширение не запустится, а штатное меню останется доступным. Откройте **Extensions → Manage Extensions** и отключите UI Studio, чтобы безопасно проверить конфликт темы.
3. Для возвращения к нормальному запуску удалите `stui_safe=1` из URL и перезагрузите страницу.
4. Если способ не помогает, временно переместите папку `SillyTavern-UI-Studio` за пределы каталога расширений на устройстве/сервере, где запущена SillyTavern, и перезапустите её. Папку не нужно удалять.

## Установка из ZIP вручную

1. Распакуйте архив. Внутри должна быть папка `SillyTavern-UI-Studio`, а в ней файлы `manifest.json`, `index.js`, `style.css`.
2. Закройте SillyTavern.
3. Перенесите **всю папку** `SillyTavern-UI-Studio` в один из каталогов вашей установки:
   - Для текущего пользователя (современные версии): `SillyTavern/data/default-user/extensions/SillyTavern-UI-Studio/` — если пользователь не `default-user`, используйте папку своего пользователя.
   - Для всех пользователей: `SillyTavern/public/scripts/extensions/third-party/SillyTavern-UI-Studio/`.
4. Запустите SillyTavern, обновите страницу. При необходимости проверьте, что UI Studio включено в **Extensions → Manage Extensions**.
5. У края чата появится стрелка `>`; нажмите её и выберите **Theme Studio → Общее** для настройки положения и вида стрелки.

Если уже установлена более ранняя версия, обновите расширение до версии 0.3.0. Сохранённые темы и переписки не удаляются.

> Встроенная кнопка **Install Extension** SillyTavern обычно принимает URL Git-репозитория, а **не ZIP**. Этот архив предназначен для ручной установки. Чтобы установить по ссылке, содержимое папки сначала нужно опубликовать в Git-репозитории.

### Установка на телефоне

- Если SillyTavern запускается в **Termux на Android**, откройте её файловую папку в Termux/файловом менеджере, распакуйте расширение по одному из путей выше и перезапустите сервер.
- Если SillyTavern открыта в браузере телефона, но запущена **на ПК или сервере**, папку расширения нужно поместить **на тот ПК/сервер**, где работает SillyTavern, а затем обновить браузер телефона.
- На iOS расположение файлов зависит от способа запуска сервера; одного Safari недостаточно для установки локального ZIP на удалённую SillyTavern.

## Если что-то пошло не так

1. Откройте стрелку слева → **Theme Studio → Общее → Показать верхнее меню**.
2. При необходимости нажмите **Сбросить оформление**, проверьте результат и затем **Сохранить изменения** — это не удаляет сохранённые темы.
3. Если меню не открывается, отключите расширение в **Extensions → Manage Extensions** или временно уберите его папку из каталога расширений и перезапустите SillyTavern. Ваши переписки и карточки персонажей расширение не редактирует.

## Ограничения первой версии

- Вставить адрес страницы с картинкой вместо прямой ссылки на PNG нельзя: используйте ссылку на файл `.png` или сохраните картинку на телефон. Некоторые сайты защищают изображения от показа по внешней ссылке.
- Разработка выполнена по HTML-разметке актуальной ветки **SillyTavern Release**. На конкретной установке и с другими темами/расширениями возможны конфликты CSS, особенно на маленьких экранах. Нужна финальная проверка на вашем телефоне.
- Некоторые стили самой SillyTavern или сторонних CSS-тем могут перекрывать настройки UI Studio.
- Мини-чат в Theme Studio предназначен для оценки настроек **до сохранения**. Он не повторяет сторонние CSS-темы пиксель в пиксель и использует условные аватары AI/Я; окончательный вид настоящего чата может немного отличаться.
- Стрелка выводится поверх переписки. При тексте вплотную к краю возможна небольшая зона перекрытия — перенесите стрелку на другую сторону или по высоте, где она не мешает.
- Иконки заменяются в созданном левом меню. **Полная замена каждого значка внутри SillyTavern** пока не реализована.
- Декор размещается поверх чата относительно экрана, а не внутри конкретных сообщений. Он не входит в сообщения, отправляемые модели.
- Пользовательские шрифты выбираются из доступных браузеру/system font families. Загрузка `.ttf`/`.woff` пока не предусмотрена.
- Профили и импортируемые файлы считаются пользовательскими настройками: не загружайте JSON из недоверенных источников. Внешних библиотек нет. По ссылкам PNG загружаются с указанных пользователем HTTPS-сайтов; собственные загруженные PNG сохраняются в настройках SillyTavern.
- Декор — плавающий слой над чатом, а не вложение в конкретное сообщение. Если другое расширение рисует полноэкранное окно поверх чата, декор будет скрыт этим окном по задумке.
